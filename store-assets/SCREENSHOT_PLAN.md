# 商店图片清单

## 必需资产

- `icon-128.png`：128×128 PNG，实际图形约 96×96，四周透明留白。
- `promo-small-440x280.png`：440×280 PNG。
- 至少一张 1280×800 PNG/JPEG 实际产品截图，建议准备以下 3 张：
  1. `screenshot-01-popup-1280x800.png`：扩展弹窗、已登录状态、文本导入和完成时间预估。
  2. `screenshot-02-standard-field-1280x800.png`：普通输入框选择和悬浮控制面板。
  3. `screenshot-03-canvas-mode-1280x800.png`：Google Docs 或合法测试画布中的当前页面光标模式。

## 截图要求

- 必须来自最新版扩展的真实界面，不制作不存在的功能。
- 使用测试文档和测试账号，避免出现个人邮箱、真实论文、令牌或其他敏感数据。
- 正方形边角、无外部留白、清晰可读。
- 截图推荐 1280×800；商店会缩小显示，请避免堆放大量小字。

## 可选资产

- `promo-marquee-1400x560.png`：用于争取商店推荐位。
