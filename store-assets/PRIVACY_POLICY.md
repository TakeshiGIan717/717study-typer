# 717study.com 打字机隐私政策（上架草稿）

生效日期：发布时填写

717study.com 打字机（以下简称“本扩展”）由 717study.com 提供。本政策说明本扩展如何处理用户数据。

## 处理的数据

1. 登录状态：本扩展在 717study.com 页面上下文中读取现有登录令牌，并仅将其发送至 717study.com 自有接口 `/api/user/account` 验证会话是否有效。扩展后台只接收“已登录/未登录”的结果，不保存登录令牌、密码或用户资料。
2. 用户提供的文档内容：用户粘贴或导入的 TXT、Markdown、DOCX 内容仅在用户设备上的浏览器内解析和处理，用于输入到用户主动选择的网页编辑区域。正文不会上传到 717study.com，也不会写入扩展的持久存储。
3. 使用设置：WPM、速度波动、停顿概率、误触概率和英文整词概率保存在 Chrome 扩展本地存储中，用于恢复用户偏好。
4. 当前网页交互：本扩展仅在用户主动调用后访问当前标签页，用于选择编辑区域、显示控制面板和执行用户请求的文本输入。

## 数据分享

除上述登录状态验证请求外，本扩展不会向 717study.com 或其他第三方发送用户导入的正文、网页内容或浏览历史。我们不会出售用户数据，也不会将数据用于广告、信用评估或与扩展单一用途无关的目的。

## 数据保留与删除

导入的正文仅保存在当前扩展弹窗或页面会话的内存中，关闭相关页面或扩展会话后不再由本扩展保留。用户可通过 Chrome 的扩展管理页面清除扩展数据或卸载扩展，以删除已保存的节奏设置。

## 权限说明

- activeTab：在用户主动调用后访问当前标签页。
- scripting：注入输入框选择器和页面控制面板。
- storage：保存非敏感的节奏偏好。
- debugger：仅在“当前页面光标”输入任务期间使用 Chrome Input 协议向 Canvas 或自定义编辑器输入；任务完成、停止或关闭面板后断开。
- https://www.717study.com/*：验证用户在 717study.com 的登录状态。

## 信息安全与有限使用

我们使用 HTTPS 传输登录验证请求，并将数据使用限制在本扩展向用户明确展示的单一用途范围内。本扩展对从 Google API 或 Chrome API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。

## 儿童隐私

本扩展不面向法律规定年龄以下的儿童，也不会有意收集儿童个人信息。

## 政策变更

如本政策发生重大变化，我们将更新生效日期，并通过网站或扩展更新说明告知用户。
