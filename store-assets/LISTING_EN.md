# Chrome Web Store Listing (English)

## Name

717study.com Typer

## Short description

Enter local text and DOCX content at a configurable pace in web editors you are authorized to use.

## Detailed description

717study.com Typer is a web text-entry assistant. Paste text or locally import TXT, Markdown, and DOCX files, select a web editor you are authorized to use, and enter the content using configurable WPM and timing settings.

Key features:

- Supports input, textarea, and contenteditable fields.
- Current-cursor mode for Google Docs, online Office editors, and canvas-based editors.
- Parses DOCX files locally in the browser while preserving paragraphs, line breaks, and table text structure.
- Configurable WPM, timing variation, random pauses, English typo correction, and whole-word entry ratio.
- Live character count and completion-time estimate.
- Start, pause, resume, and emergency stop controls.
- Available to users signed in to 717study.com.

The extension acts only after a user gesture and only on the active tab. Imported document text is not uploaded to the developer's servers or stored persistently by the extension. Use only on pages you are authorized to edit, for accessibility assistance, and for lawful testing. Do not use for academic cheating or unauthorized activity.
