# 717study.com 打字机 Chrome 扩展

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `chrome-extension`。
5. 建议在扩展菜单中将“717study.com 打字机”固定到工具栏。

开发版文件更新后，请回到 `chrome://extensions/` 点击本扩展的“重新加载”。

## 使用

1. 先登录 [717study.com](https://www.717study.com/#/SignIn)。扩展启动和真正开始输入前都会验证登录状态，登录用户可免费使用。
2. 打开你有权操作的网页，点击扩展图标。
3. 粘贴文本或导入 TXT、Markdown、DOCX，并设置节奏。弹窗会实时显示字数、预计完成时间和典型波动范围。
4. 点击“加载到当前页面”，页面右上角出现控制面板。
5. 普通 input、textarea、contenteditable 使用“点选普通输入框”。
6. Google Docs、Canvas、自定义编辑器或无法点选的区域使用“当前页面光标”：先启用该模式，再到编辑区域点好光标，最后按开始。

### 当前页面光标模式

这个通用模式适用于 Google Docs、在线 Office、Canvas 编辑器、白板和使用隐藏输入目标的网站，不依赖网页的 DOM 输入框结构。悬浮按钮按下时不会主动夺走编辑焦点。

当前光标模式需要 `debugger` 权限，通过 Chrome DevTools Protocol 的 `Input` 域向当前标签页输入文字。扩展只在输入任务运行期间连接该标签页，完成、急停或关闭面板时立即断开。如果该标签页正开着开发者工具或被其他调试器连接，需先断开后再试。

DOCX 会保留段落、换行和表格行列文本。公式显示为 `[公式: …]`，图片或图表显示为 `[图片或图表]`，需要根据目标编辑器手动插入。普通输入框不能保留 Word 字体、颜色和页面布局。

扩展申请 `activeTab`、`scripting`、本地设置存储、717study.com 登录验证和用于当前页面光标输入的 `debugger` 权限。登录令牌只在 717study.com 页面上下文中用于调用网站自己的 `/api/user/account`，扩展后台仅接收登录与否，不保存令牌或用户资料。它不能在 `chrome://`、Chrome 网上应用店等受保护页面运行。仅用于用户有权操作的页面与合法测试。
导入的正文不会持久保存到扩展存储；只有 WPM 等节奏设置会保留。
